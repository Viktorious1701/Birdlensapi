# Story 5.4: Initiate PayOS Payment Link

## Status
Done

## Story
**As a** Standard Mobile User,
**I want** to initiate a payment for the "ExBird" subscription via PayOS,
**so that** I can receive a checkout link to upgrade my account.

## Acceptance Criteria
1. A `POST /api/v1/payos/create-payment-link` endpoint is created that accepts a `subscriptionId`.
2. The service fetches the plan details and generates a unique `orderCode` (integer) for the transaction.
3. The service calls the PayOS API to create a payment link with the price, description, and configured `returnUrl` and `cancelUrl`.
4. The service stores the mapping of `orderCode` -> `userId` and `subscriptionId` in Redis with a TTL of 24 hours to track the pending transaction.
5. The endpoint returns a `200 OK` containing the `checkoutUrl` provided by PayOS.
6. The endpoint is secured with JWT authentication.
7. A test verifies that the PayOS API is called correctly (mocked) and that the pending state is saved to Redis.
