# Story 5.3: Fetch Subscription Plans API

## Status
Done

## Story
**As a** Standard Mobile User,
**I want** to fetch a list of available subscription plans,
**so that** I can choose one to purchase and upgrade my account.

## Acceptance Criteria
1. A `GET /api/v1/subscriptions` endpoint is created.
2. The endpoint returns a list of all active subscription plans from the `subscriptions` table.
3. The response includes: `id`, `name`, `description`, `price`, `durationDays`, and `productId`.
4. The endpoint is secured with JWT authentication.
5. An integration test verifies that the plans are returned correctly and that standard users have access to this list.

## Dev Notes
- **Payload Shape**: As designed, this is an unpaginated return collection since subscription tier variants traditionally stay well below thresholds requiring cursor boundaries.
- **Serialization Quality**: Verified `BigDecimal` serializes to standard numerics accurately inside Jackson via integration tests (`$.data[0].price == 9.99`).
